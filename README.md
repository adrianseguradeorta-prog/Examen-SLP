## Desarrollo posterior

Repositorio oficial: https://github.com/adrianseguradeorta-prog/Examen-SLP

El usuario exige aprobación antes de iniciar la implementación principal. Tras aprobar: inicializar Next.js/TypeScript, fijar versiones y lockfile, implantar checks y migraciones probadas. `.env.example` contiene solo nombres y valores vacíos. No guardar datos de estudio, audios ni credenciales en Git. Los documentos expresan propuestas, salvo hechos acompañados de fuentes.
